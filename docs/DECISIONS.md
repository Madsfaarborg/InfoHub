# Implementation decisions

## 24 November 2026

- Keep the hub English, local, and account-free, as confirmed by the owner.
- Preserve the synced root AGENTS.md. Maintain repository guidance in src/AGENTS.md and learning records here.
- Use Next.js App Router with TypeScript, system fonts, and plain CSS design tokens. The interface needs no styling framework to implement this scope.
- Keep search in browser memory with deterministic, editable task interpretation.
- Use a typed public starter catalog and optional validated local published bundle. Content publishing is a host-side CLI operation.
- Distinguish supported provider settings and prices from editorial task-fit suggestions. No invented benchmark scores.
- Unconfigured local Qwen appears as a deployment option, not an available hosted service.
- Start price comparison with transparent token assumptions. Enable measured quality comparison only for compatible published results.
- Delegate bounded research and pure logic to Sol 6.1 medium; keep shared contracts, dependencies, and integration with the coordinator.
- Retain the porcelain, graphite, and vermilion direction with generous whitespace.
- Use 6-Astra only for complex delegated tasks, as requested by the owner. Routine review and verification stay on the smaller models.
- Mount only the published directory in Docker. Match the container process to the host publisher's UID and GID so it can read the owner-only bundle.
- Keep business workflows in the same local task finder. Use a separate image settings and pricing record for creative workflows, with no provider calls from InfoHub.
- Bundle public creative content for new installs. Existing installations can adopt it through a reviewed additive publication that preserves team guidance and creates a rollback point.
- Keep broad Artificial Analysis discovery in its own searchable directory. Task results stay limited to three curated choices with exact settings. Authorized source data is refreshed into a separate host snapshot and never auto-promoted into recommendations.
- Prepare editorially approved daily news and weekly catalog changes as public content pull requests. GitHub and Vercel run the same CI command. The bundled release supplies hosted builds while a local operational catalog still takes precedence on a self-hosted installation.
- Explicitly opted-in scheduled runs may ship confirmed public news and high-confidence catalog edits. The publishing command uses a fresh isolated checkout and protected auto-merge. Keep all other findings in private research output.
- Store provider-reported scores with their model records, publication date, source, and test conditions. The cost-versus-quality chart requires cost and quality measured by the same evaluation.
