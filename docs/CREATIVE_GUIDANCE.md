# Creative and business guidance

Sources checked 24 November 2026. The starting choices below are editorial judgments based on supported workflows. Each team should compare results using its own approved briefs and reference assets.

## Which image tool to try

- **Campaign concepts and social visuals:** Start with Nano Banana 2.1 in Google AI Studio. Try 1K drafts and select the aspect ratio for the channel. The standard API lists about $0.0336 per 1K image output. Input, text, thinking, and optional search grounding can add charges. [Google image guide](https://aistudio.google.com/docs/image-generation) · [Pricing](https://aistudio.google.com/docs/pricing#gemini-nano-banana-2.1)
- **Edits to an existing photo:** Try GPT Image 2.6 Sunburst for a concrete change with clear instructions about what stays fixed. Specify the area to edit and inspect exact product details against the source. API cost depends on output size, quality, and inputs. [OpenAI model and rates](https://developers.openai.com/api/docs/models/gpt-image-2.6-sunburst) · [Editing guide](https://developers.openai.com/api/docs/guides/image-generation)
- **Poster or image with lettering:** Try Ideogram 4.6 with a short exact headline. The published text-only rate through 2K is $0.06 at medium quality. Set final dates, prices, legal text, and approved fonts as editable layers. Qwen Image 3.0 Pro is another option for multilingual layouts. Its international 1K output rate is $0.04, with separate reference-image charges. [Ideogram 4.6](https://ideogram.ai/models/4.6/) · [QwenCloud rates](https://docs.qwencloud.com/models/qwen-image-3-0-pro)
- **Existing design and reference workflows:** Adobe Firefly Image5 is an option for teams working in Adobe. Confirm the model and credits in the browser. FLUX 3 Image is an API option for combining approved references and has a published $0.048 1K generation or edit rate. [Adobe Image5](https://developer.adobe.com/firefly-services/docs/firefly-api/guides/how-tos/cm-generate-image/feature-guide) · [Adobe plans](https://www.adobe.com/products/firefly/plans.html) · [Black Forest Labs pricing](https://bfl.ai/pricing)
- **Local image drafts:** Qwen-Image-2512 can be installed locally with a compatible Diffusers setup. This is a separate downloadable model from hosted Qwen Image 3.0 Pro. Verify the host, runtime, and hardware cost before marking it available. [Qwen model card](https://huggingface.co/Qwen/Qwen-Image-2512)

The image catalog stores checked dates and the unit for each rate. Subscription credits, actual hardware cost, and a 1K API output charge describe different things. An image draft and its revisions can have separate costs.

## Business workflows

- **Marketing and sales:** Start with approved product facts, an audience, a channel, and a tone. Ask for options or a proposal outline. Review technical promises, metrics, and customer quotes before use.
- **Presentations:** Ask for a story, a slide outline, speaker notes, or image briefs using approved source notes. Build the final deck in the team's slide editor so the text and claims can be reviewed.
- **Data and spreadsheets:** Start from the sheet's structure and a small permitted sample. Ask for formulas, a plain-English trend summary, or a chart choice. Check calculations and reported totals in the original workbook.

Use the expanded daily research prompt to capture releases or price changes relevant to these workflows. Refresh affected catalog records through reviewed publishing. No live image generation, provider API credentials, or task uploads are part of this release.
